# AMNA Beauty Parlour — React Demo

A luxury black + gold, glass-inspired responsive demo built with React and Vite.

## Run

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```

## Included
- Responsive luxury landing page
- AMNA logo + supplied bridal image + supplied decorative frame
- Services cards with images and service modals
- Filterable gallery
- Bridal packages
- Rate list modal
- Appointment demo form + toast confirmation
- Mobile navigation
- Glass / gold visual system, hover effects and subtle motion
- Remote demo images are used for several service/gallery cards; replace these with licensed salon portfolio images before production launch.
